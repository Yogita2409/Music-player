# 🎵 Music Playlist App (MERN)

## 📌 Description
This is a Music Playlist web application built using MERN stack where users can:
- Upload songs
- Create playlists
- Play songs
- Delete and update playlists

## 🚀 Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js

## 📂 Project Structure
- frontend/ → React app
- backend/ → Node + Express server

## ▶️ How to Run Locally

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start
